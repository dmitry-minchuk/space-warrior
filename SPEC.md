# Space Warrior — техническое задание

2D-скролл-шутер в духе вертикальных «арканоидов» начала 2000-х (Tyrian, Raptor, Star Defender). Игрок управляет небольшим космическим кораблём в нижней части экрана, фон скроллится сверху вниз, враги атакуют из верхней части. 20 уровней с нарастающей сложностью, босс в конце каждого уровня. Сохранений нет — каждая партия начинается с нуля, есть только пауза. Оружие, здоровье и бонусы выпадают из уничтоженных врагов.

Документ организован поэтапно: каждый этап описывает цель, объём работ, критерии готовности (Definition of Done) и зависимости. Этапы выполняются последовательно, но внутри этапа задачи можно распараллеливать.

---

## 0. Общее: целевая платформа, стек, конвенции

### 0.1. Целевая платформа

- **Основная цель**: macOS 13+ (Apple Silicon и Intel), запуск как нативное приложение `.app` / дистрибутив `.dmg`.
- **Доп. цель (бесплатно)**: запуск в современных браузерах (Chrome, Safari, Firefox) — тот же билд, открытый в браузере.
- **Разрешения**: окно с фиксированным внутренним разрешением логики (1920×1080 виртуальные пиксели), масштабируемое в окне с letterbox по аспекту 16:9. На Retina рендер в физических пикселях.
- **Производительность**: стабильные 60 FPS на M1 при ~3000 одновременных частиц, ~150 спрайтах в кадре, 4–6 параллакс-слоях фона.

### 0.2. Технологический стек

| Компонент | Выбор | Обоснование |
|---|---|---|
| Язык | TypeScript 5.x (strict) | Типобезопасность, быстрая итерация |
| Рендер | PixiJS 8 (WebGL2/WebGPU) | Мощный 2D-рендер, шейдеры, batch-рендеринг |
| Бандлер | Vite | Быстрый dev-server, HMR, простая сборка |
| Нативная оболочка | Tauri 2.x | Компактный нативный .app под macOS, без жирного рантайма |
| Аудио | Howler.js | Простой кросс-браузерный звук, спатиальные эффекты |
| Физика / коллизии | Самописная (AABB + circle), без полноценного движка | Шутеру не нужен Box2D — достаточно проверки пересечений |
| Тестирование | Vitest (юнит), Playwright (визуальные смоук-тесты) | |
| Линт / формат | ESLint + Prettier | |
| CI | GitHub Actions | Сборка под macOS (arm64 + x64), линт, тесты |

### 0.4. Конвенции

- **Координаты**: логические в виртуальных 1920×1080. Y растёт вниз. Игрок свободно перемещается в окне игры (с зоной перемещения, оставляющей место под HUD).
- **Время**: фиксированный шаг логики 60 Гц (`dt = 1/60`). Рендер — по requestAnimationFrame, при просадках логика догоняется до 4 шагов за кадр.
- **ID и пулы**: все «горячие» сущности (пули, частицы) хранятся в object pool, без аллокаций в горячем пути.
- **Сериализация**: уровни — JSON-файлы, описывающие волны, фон, музыку, босса.

### 0.5. Definition of Done для всего проекта

1. Игра запускается на macOS 13+ как `.app`.
2. Все 20 уровней проходимы без падений, средний FPS ≥ 55 на M1.
3. Управление с клавиатуры + опционально геймпад (XInput/MFi).
4. Звук и музыка работают; есть регуляторы громкости.
5. Пауза, рестарт, главное меню, экран Game Over.
6. Нет утечек памяти за час геймплея (контроль через Chrome DevTools / Instruments).

## Этап 1. Каркас движка и базовый рендер

**Цель**: иметь окно, отрисовать спрайт, читать ввод, иметь стабильный game loop.

### Объём работ

1. Инициализация репозитория, ESLint/Prettier, tsconfig (strict), Vite-конфиг.
2. Tauri-обвязка: окно 1280×720, без рамки или с системной (на выбор), фуллскрин по F11.
3. PixiJS-приложение с автоматическим масштабированием (canvas resize → fit-to-window с letterbox).
4. Game loop с фиксированным таймстепом и аккумулятором.
5. Сцен-менеджер (`Scene` — `Boot`, `MainMenu`, `Game`, `Pause`, `GameOver`).
6. Загрузчик ассетов: атласы PNG+JSON, аудио, шрифты, шейдеры; экран загрузки с прогресс-баром.
7. Система ввода: клавиатура (WASD/стрелки/Space/Shift/Esc), опц. геймпад через Gamepad API.
8. Базовая ECS-облегчёнка: `Entity = id`, `Component = плоский объект`, `System = функция (world, dt)`.

### Definition of Done

- Запускается окно, на фоне отрисовывается тестовый спрайт.
- Чёрный квадрат двигается по WASD без рывков, FPS-счётчик стабилен.
- `npm run dev` / `npm run build` / `npm run tauri build` работают.

## Этап 2. Игрок и управление

**Цель**: рабочий корабль игрока с базовой стрельбой и здоровьем.

### Объём работ

1. **Спрайт корабля**: основной + анимация дюз (отдельные кадры или шейдер-glow), визуальное наклонение влево/вправо при движении (sprite-sheet 3 кадра: ровно/влево/вправо).
2. **Движение**: 4 направления + диагонали, с ускорением и торможением (не мгновенное), верхняя граница перемещения ≈ 60% высоты экрана, нижняя — у самого края.
3. **Стрельба**: автоматическая при удержании Space, базовое оружие — двойная пуля, скорострельность 8 выстрелов/сек.
4. **Здоровье**: 100 HP, нет регенерации (только дропы).
5. **Бомба/смарт-бомба**: 2 заряда на старте, очищает экран от снарядов и наносит урон по всем врагам в кадре (Shift или X).
6. **Невулнерабельность после получения урона**: 1 секунда мигания.
7. **Смерть**: 3 жизни на партию, при потере всех — GameOver.

### Definition of Done

- Корабль управляется плавно, стреляет, погибает, перезапускается с уровня 1.
- Бомба работает и тратит заряд.

## Этап 3. Архитектура врагов: базовая система

**Цель**: универсальный конвейер для создания, спавна, поведения, рендера и уничтожения врагов.

### Объём работ

1. **EnemyArchetype** — описание архетипа (визуальный пресет): спрайт, HP, скорость, тип движения, вооружение, поведение при выходе из экрана, лут-таблица. Один и тот же ассет = один архетип = одинаковые характеристики (требование пользователя).
2. **Spawner-система**: спавн по таймлайну уровня; поддержка формаций (V, линия, дуга, круг, ромб).
3. **Поведенческие модули (movement)**:
   - `straight` — прямо вниз
   - `sine` — синусоидой
   - `dive` — пикирует к низу, потом уходит вверх
   - `strafe` — заходит сбоку, проходит горизонтально, уходит
   - `hover` — заходит и зависает в верхней трети, стреляя
   - `chase` — поворачивается в сторону игрока
   - `orbit` — облетает точку
   - `path` — движение по заранее заданной кривой Безье (для скриптовых волн)
4. **Поведенческие модули (combat)**:
   - `none`
   - `forward_single` — одиночная пуля вниз
   - `forward_burst` — очередь из 3
   - `spread_3` / `spread_5` — веер
   - `aimed` — целится в игрока
   - `lob_bomb` — параболические бомбы
   - `mine` — оставляет мины
   - `laser_charge` — заряжает и пускает луч
   - `chain_lightning` — цепная молния по близости
5. **Коллизии**: AABB + опционально circle, broad phase через uniform grid (ячейка 128 виртуальных пикселей).
6. **Лут-таблица**: вероятности дропа (см. этап 6) с весами, проверяется при уничтожении.

### Definition of Done

- В тестовой сцене можно заспавнить волну из 10 врагов разных архетипов, они корректно двигаются, стреляют и умирают.
- Профайлер показывает стабильные 60 FPS при 200 одновременных сущностях.

### Варианты элиты (этап для 16–20 уровней)

- **Elite Scout**: ×2 HP, ×1.5 скорость, цветовая палитра меняется на фиолетовую.
- **Elite Fighter**: добавлен второй ствол, ×2 скорострельность.
- **Elite Bomber**: бомбы взрываются на кластеры.
- **Elite Interceptor**: 2 пике подряд.
- **Elite Heavy**: щит, поглощающий 50 урона.

Элиты — те же визуальные модели + наложенный shader-tint и доп. эффект (контурное свечение через outline-шейдер), чтобы игрок узнавал, но визуально отличал.

### Definition of Done

- Все 12 архетипов реализованы, заведены в реестре, у каждого свой спрайт, поведение, оружие, лут.
- Можно вызвать любой архетип по строковому ключу.
- Для каждого архетипа есть мини-сцена ручного тестирования.

## Этап 5. Оружие и снаряды

**Цель**: набор пушек игрока и врагов, единая система снарядов.

### Снаряды (общая система)

- Базовая сущность `Projectile`: спрайт, скорость, направление, урон, владелец (player/enemy), время жизни, хитбокс, опц. поведение (homing, parabola, beam).
- Пул на 1000 снарядов, тайл-сжатие хитбоксов.

### Оружие игрока (выпадает из врагов, см. этап 6)

| Оружие | Уровни | Описание |
|---|---|---|
| Pulse Gun | 1–3 | Стартовое, двойная пуля. Левел-ап: +ствол, +скорострельность |
| Spread Shot | 1–3 | Веер на 3/5/7 пуль |
| Plasma Cannon | 1–3 | Медленные тяжёлые сгустки, большой урон, пробивает |
| Laser Beam | 1–3 | Непрерывный луч, расходует «перегрев» |
| Homing Missiles | 1–3 | 1–3 самонаводящиеся ракеты в залпе |
| Wave Beam | 1–3 | Синусоидальная волна, проходит сквозь врагов |
| Lightning | 1–3 | Цепная молния по ближайшим целям |

Одновременно у игрока активна одна основная пушка + бомбы. Подбор того же оружия повышает его уровень (макс 3). Подбор другого оружия — заменяет текущее на 1-й уровень (классическая механика, простая и понятная).

### Оружие врагов

Описано в этапе 4 (по архетипам). Все вражеские снаряды визуально отличаются по цвету от игроковых (враги — оранжевый/красный/фиолетовый, игрок — голубой/зелёный).

### Definition of Done

- Все 7 пушек игрока работают и визуально различимы.
- Подбор оружия меняет/прокачивает пушку.
- Снаряды попадают, считают урон, не утекают по памяти.

## Этап 6. Дропы: оружие, здоровье, бонусы

**Цель**: при уничтожении врага с заданной вероятностью выпадает капсула, медленно дрейфующая вниз; при подборе даёт эффект.

### Типы дропов

| Тип | Иконка/цвет | Эффект | Базовая вероятность |
|---|---|---|---|
| Health (S) | Зелёный плюс, маленький | +15 HP | 5% |
| Health (L) | Зелёный плюс, большой | +40 HP | 1.5% (только из крупных врагов и боссов) |
| Weapon: Pulse | Голубой шеврон | Установить/прокачать Pulse | 3% |
| Weapon: Spread | Жёлтый шеврон | Spread | 2% |
| Weapon: Plasma | Розовый шеврон | Plasma | 1.5% |
| Weapon: Laser | Белый шеврон | Laser | 1.5% |
| Weapon: Missiles | Оранжевый шеврон | Missiles | 1.5% |
| Weapon: Wave | Фиолетовый шеврон | Wave | 1% |
| Weapon: Lightning | Электрический жёлтый | Lightning | 1% |
| Shield | Синий круг | Щит, поглощает 100 урона или 10 секунд | 1% |
| Speed Boost | Зелёная стрелка | +30% скорость на 15 секунд | 2% |
| Damage Boost | Красный крест | ×2 урон на 10 секунд | 1% |
| Bomb | Жёлтая бомба-сфера | +1 заряд бомбы (макс 5) | 2% |
| Score Gem | Кристалл, разные размеры | Очки 100/500/2000 | 8% |

Веса лут-таблиц у каждого архетипа свои: у Scout — больше Score Gem, у Heavy Assault — больше шанс оружия, у Boss — гарантированный Health (L) + случайное оружие 3 уровня.

### Поведение дропа

- Падает вниз со скоростью 80 px/s (медленнее врагов).
- Слегка пульсирует/вращается (shader tint).
- При контакте с игроком — подбирается, проигрывается звук и всплывающий текст.
- Через 12 секунд начинает мигать, через 15 — исчезает.

### Definition of Done

- При убийстве врагов выпадают дропы согласно таблице.
- Подбор работает для всех типов.
- Эффекты с таймером корректно затухают.

## Этап 7. Структура уровня и редактор данных

**Цель**: декларативное описание уровня (JSON/TS), переиспользуемый раннер уровней.

### Формат уровня

```jsonc
{
  "id": "level-03",
  "name": "Asteroid Belt",
  "duration": 180,                  // ориентир в секундах
  "background": {
    "music": "audio/lvl-03.ogg",
    "layers": [
      { "type": "stars",      "speed": 20,  "density": 0.5 },
      { "type": "nebula",     "speed": 35,  "sprite": "nebula_purple" },
      { "type": "planet",     "speed": 50,  "sprite": "planet_gas_giant", "x": 1400 },
      { "type": "base",       "speed": 80,  "sprite": "base_burning_01", "spawnAt": 90 }
    ]
  },
  "waves": [
    { "at": 2,  "spawn": "scout", "count": 6, "formation": "v", "side": "top" },
    { "at": 8,  "spawn": "fighter", "count": 4, "formation": "line" },
    { "at": 20, "spawn": "drone", "count": 12, "formation": "swarm_path:zigzag" },
    { "at": 40, "spawn": "bomber", "count": 2 },
    /* ... */
  ],
  "boss": {
    "id": "boss-03-cyber-crab",
    "spawnAt": 165,
    "music": "audio/boss-03.ogg"
  }

```

### Раннер уровня

- Реализует таймлайн, спавнит волны, переключает музыку, спавнит босса, отслеживает условие победы (босс убит + волны закончились).
- При смерти игрока — экран Game Over, рестарт уровня (или с начала кампании — решается в меню).

### Definition of Done

- Тестовый уровень JSON загружается, проигрывается от начала до босса.
- Замена JSON не требует пересборки в dev-режиме (HMR).

## Этап 8. 20 уровней: прогрессия и контент

**Цель**: дизайн всех 20 уровней с нарастающей сложностью и тематическим разнообразием.

### Прогрессия

| Уровни | Тема | Новые враги | Сложность |

## Этап 10. Фоновая графика и параллакс

**Цель**: глубокий, насыщенный космический фон с многоплановым параллаксом, чтобы создать атмосферу «начала 2000-х», но с современной детализацией.

### Слои (сверху вниз по глубине)

1. **Дальние звёзды**: процедурные точки на тёмном фоне, скорость 5 px/s, плотность 200/экран.
2. **Средние звёзды**: чуть крупнее, с шейдер-glow, скорость 15 px/s.
3. **Туманности**: большие полупрозрачные спрайты с blend mode `add`, скорость 25 px/s.
4. **Планеты**: 2K-PNG-спрайты с лёгкой собственной анимацией (вращающаяся атмосфера через rotating noise-шейдер), скорость 40–60 px/s.
5. **Космические базы / обломки**: детальные ассеты — заброшенные, горящие, разрушенные. Спрайты с partial-анимацией (мерцающие огни, языки пламени через частицы, искры).
6. **Ближняя пыль / искры**: быстрые мелкие частицы, скорость 100 px/s.

### Тематические наборы

Каждые 3–4 уровня — новая палитра/набор фоновых ассетов:

- Уровни 1–3: околоземное пространство (Земля, Луна, голубые туманности).
- Уровни 4–7: индустриальные станции, серо-оранжевая палитра.
- Уровни 8–10: тёмный сектор, красно-фиолетовая.
- Уровни 11–14: туманности и аномалии, ярко-фиолетово-зелёная.
- Уровни 15–17: чужой улей, биолюминесцентные цвета.
- Уровни 18–20: финальный сектор, мрачные тёмно-синие тона с золотыми акцентами.

### Шейдеры/эффекты

- **Bloom** (постпроцесс) на ярких объектах.
- **Distortion** при взрывах боссов и около чёрных дыр.
- **Scanlines** опционально как «ретро-режим» (галочка в настройках).
- **Chromatic aberration** на границах экрана в моменты получения урона.

### Definition of Done

- 6 фоновых сетов, переключаются между уровнями.
- Параллакс из 4–6 слоёв, плавный без артефактов.
- Bloom и distortion включаются и не роняют FPS ниже 55.

## Этап 11. Графика и пайплайн ассетов

**Цель**: высокая детализация всех ключевых объектов (корабли, базы, планеты) без перехода в «мультяшный» или «примитивный» стиль.

### Стиль

- Полу-реалистичный sci-fi pixel-detail. Цели — Tyrian 2000, Raptor: Call of the Shadows, Space Tactical Warrior, но в современном разрешении.
- Корабли — 256×256 px (игрок, обычные враги), 512×512 px (тяжёлые), 1024×1024 и больше (боссы).
- Источники света: на каждом корабле — направленный, плюс эмиссивные пятна (дюзы, окна, орудия).

### Пайплайн

1. **Концепты**: можно генерировать в DALL-E / SDXL по моодборду, затем дорабатывать в Aseprite / Krita / Photoshop.
2. **Чистка и нормализация**: убрать фон, выровнять центр, привести к канонической ориентации (нос — вверх).
3. **Атласы**: TexturePacker экспорт `multipack` PNG + JSON.
4. **Аниматики**: для боссов и крупных кораблей — отдельные анимации частей (вращающиеся турели, открывающиеся ангары).
5. **Версионирование**: сырые исходники — в `assets/raw/`, билд — `assets/sprites/`.

### Графические возможности железа

- Использование WebGL2 batch-рендера PixiJS — отрисовка тысяч спрайтов в одном draw call.
- Шейдеры для эффектов вместо лишних спрайтов.
- WebGPU как опция (Pixi 8 поддерживает), включать когда стабилен в Tauri / Chromium-ядре, иначе fallback на WebGL2.

### Definition of Done

- Все ассеты пробегают через единый пайплайн.
- Размер итогового бандла ≤ 200 МБ.
- Загрузка уровня ≤ 1.5 сек на M1.

## Этап 13. UI / HUD / меню

**Цель**: лаконичный, читаемый HUD в духе ретро-шутеров, современное основное меню.

### HUD (во время игры)

- Слева вверху: HP-бар + число.
- Справа вверху: счёт, уровень, время уровня.
- Слева внизу: иконка текущего оружия + уровень (1/2/3).
- Справа внизу: количество бомб, количество жизней.
- По центру сверху во время боя с боссом: HP-бар босса с именем.

### Основное меню

- Start Game / Settings / Credits / Quit.
- Settings: громкости, разрешение/полный экран, привязки клавиш, ретро-фильтр on/off.

### Пауза

- Esc → оверлей с Resume / Restart Level / Main Menu / Quit.

### Game Over / Level Cleared

- Game Over: «Восстановить чекпоинт нельзя — начать заново?».
- Level Cleared: статистика уровня (точность, время, очки) и переход дальше.

### Definition of Done

- Все экраны навигируются с клавиатуры и мыши.
- HUD не загораживает игровое поле, читается даже при ярких эффектах.

## Этап 14. Балансировка, тестирование, полировка

**Цель**: довести игру до состояния «готовый продукт».

### Балансировка

- Внутренний тулинг: dev-консоль (~ в dev-сборке) — спавн врагов, выдача оружия, инвулнерабильность, скип-уровня — для прохождения и отладки.
- Метрики уровня (логируются в файл в dev-режиме): среднее DPS игрока, среднее HP, среднее время уровня, частота получения урона.
- Целевые показатели: средний игрок без читов — проходит уровни 1–10 за ~25 минут с ≤ 3 смертями, уровни 11–20 — за ~30 минут с ≤ 8 смертями.

### Тесты

- Юнит: математика снарядов, движение врагов, лут-таблицы.
- Интеграционные: запуск каждого уровня в headless-режиме, проверка отсутствия исключений за 5 минут.
- Визуальные смоук-тесты (Playwright): скриншоты главного меню, HUD, паузы.

### Регрессии

- Профайлинг каждые ~5 этапов: память, FPS, draw calls.

### Definition of Done

- Все уровни проходимы.
- Нет утечек памяти.
- Нет жалоб профайлера на просадки ниже 55 FPS на M1 в типовых сценах.

## Этап 15. Сборка, дистрибуция и подпись под macOS

**Цель**: получить устанавливаемый `.dmg` на macOS.

### Объём работ

1. Tauri `tauri.conf.json`: bundle id `com.spacewarrior.game`, иконки, версия.
2. CI-сборка под Apple Silicon (`aarch64-apple-darwin`) и Intel (`x86_64-apple-darwin`); итоговая универсальная сборка через `lipo`.
3. Codesign и нотаризация (если есть Apple Developer аккаунт) — опционально, иначе пользователь снимает карантин вручную.
4. Создание `.dmg` через `create-dmg` или `tauri bundle`.
5. README с инструкцией установки и системными требованиями.

### Системные требования

- macOS 13+ (Ventura и новее).
- 4 ГБ свободной RAM, дискретная или интегрированная GPU с WebGL2.
- 500 МБ свободного места.

### Definition of Done

- `npm run tauri build` собирает `.dmg`, который устанавливается и запускает игру.
- Игра запускается на чистом macOS без дополнительных установок.

## Приложение A. Список рисков и митигаций

| Риск | Митигация |
